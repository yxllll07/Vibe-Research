# 交易系统 v1(纸面交易)

> 研究 / 模拟用:**不接券商、不自动下单、不是投资建议**。策略 v1 在样本外(验证期、2026-04~10)为亏损,
> 这套系统的作用是把「效果最好的那套规则」固定下来,每天自动出计划、记纸面账,用之后的真实行情继续检验。

## 策略定义(`configs/strategy_v1.json`,带哈希,只能由 `system-fit` 重新生成)

| 环节 | 规则 | 来源 |
|---|---|---|
| 股票池 | 沪深主板、非 ST / 退市整理、未停牌、上市满 5 日 | 研究方案 |
| 模式基础池 | A 有资金关注的非涨停股 · B 当日首板 · C 连板股首次断板 · D 炸板或昨日涨停今日收跌 · E 站上 20 / 60 日线的趋势股 | 研究方案的结构定义 |
| 池内打分 | M0 规则 DATA_R0_v1:每模式 4 个特征的当日截面分位等权平均(见 `results/eod_v1_20261017T182447/rules.json`) | 训练期 2024-10 ~ 2025-09 推导 |
| 候选 | 每模式前 2 名;主动槽从 A / B / D 第 1 名里取分数最高的 1 只,核心槽取 C、E 各自第 1 名 | 研究方案 |
| 仓位 | 每只 10% 权益(0.5% 风险预算 ÷ 5% 止损);主动槽、核心槽各 ≤ 50%;已持有不重复买 | 研究方案示例参数 |
| 退出 | A / B / D:T+1 开盘卖;C / E:持有到 T+5 开盘,期间触及入场价 −5% 止损 | 固定设定,未优化 |
| 成交口径 | T 日开盘价 ± 10bp 滑点;一字 / 开盘即涨停不买;T+1;跌停开盘卖不出顺延;费率按日期分段 | 交易规则 |
| 周期(市场状态) | 高斯混合 4 状态,训练期拟合,每天只用当天收盘后的市场广度判定;**过滤开关默认关闭**,状态与提示照常写进计划 | 训练期 |

### 为什么周期过滤默认关闭

| 区间 | 关闭(默认) | 开启(C 全停 + 按状态过滤) |
|---|---|---|
| 训练期 2024-10 ~ 2025-09(过滤规则就是在这段定的,偏乐观) | −34.3% | +22.2% |
| **验证期 2025-10 ~ 2026-03(事先约定的选择依据)** | **−5.4%** | −12.8% |
| 2026-04 ~ 10(已揭盲,仅参考) | −13.2% | −5.7% |

按事先约定以验证期为准,所以默认关闭;两种都没有在样本外赚钱,差别在噪声范围内。
要开启,把 `system/strategy.py` 的 `PARAMS["regime_gate"]` 改为 `True` 后重新 `system-fit`(会生成新哈希,旧计划不受影响)。

**不论开关,计划里都会提示**:退潮状态(状态 0)下做首板接力在训练、验证、2026-04~10 三段都亏损,是唯一跨期一致的周期规律。

## 每日运行

| 时间(北京) | 命令 | 产出 |
|---|---|---|
| D 日收盘后(盘后包约 17:00 后发布) | `ashare_lab/scripts/daily.sh D` | 补数据 → 重建特征 → `system/strategy_v1/pools/T/frozen.vN.json` + `frozen.vN.plan.md` → 纸面账本 `paper/status.md` |
| T 日 9:26 后(可选) | `python -m ashare_lab auction --date T --file 竞价.json` | 名单内放弃 / 保留 → `auction_decisions.json`(不可覆盖);被真实竞价数据放弃的票不进纸面账本 |
| 任意时刻 | `python -m ashare_lab paper` | 用全部已冻结计划确定性重放账本 |
| 回看 | `python -m ashare_lab system-history --start … --end …` | 历史完整模拟 |

纸面账本不保存可变状态:每次都用「全部已冻结计划 + 行情」从头重放,结果可复现,也无法事后改账。
冻结计划只增不改;冻结时刻必须早于 T 日 9:14:59。

定时运行(需要一台常驻机器;本云容器会被回收,数据会丢):

```cron
30 20 * * 1-5  cd /path/to/Vibe-Research && ashare_lab/scripts/daily.sh >> .local/ashare_lab/daily.log 2>&1
```
