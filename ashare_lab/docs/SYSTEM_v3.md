# 交易系统 v3 / v4:看 D 日,给 T 日做预期(EXPECT_v3 已保存,EXPECT_v4 为当前默认)

> **v3 已保存**:规则表 `modes_v3.EXPECT` 保持不变(首次提交 49563cf),命令加 `--rules v3` 即按 v3 运行,计划写在 `system/strategy_v3/`;
> **v4 为默认**:只在 v3 上加了一格(分歧日做 B),计划写在 `system/strategy_v4/`。见文末「v4 改进」。

> 研究 / 纸面用,不是投资建议。评价口径只有一个:**T 日开盘买入,当天收盘高于开盘 0.15% 以上算选对**。

## 为什么要重写

v2 把情绪开关写成了「D 日越热越能接力」,但开盘买入的人买的是 T 日:

- D 日高潮 → T 日 59% 是分歧;高潮次日的主线首板平均高开 3.3%,开盘买入当天收涨率三段都只有 37% ~ 39%(全市场约 46% ~ 48%)。
- 热门身份(主线、龙头、涨停、炸板)的溢价在 9:25 竞价里已经兑现:按竞价跳空分档,没有一组能稳定超过 55%。
- 赚钱效应没被定价的时候,是情绪冷、刚开始回暖的时候:冰点 / 修复次日的首板高开少,收涨率反而高。

## 规则

| D 日阶段 | T 日预期 | T 日开盘买 |
|---|---|---|
| 冰点 | 九成转修复 | B 首板接力、A 首板预判 |
| 修复 | 约一半发酵、四成震荡 | B、A |
| 震荡 | 近半继续震荡、三成多发酵 | B |
| 退潮 | 过半转修复 | B |
| 发酵 / 高潮 / 分歧 | 易转分歧或方向不明 | 不买 |

1. **D 日晚**(`plan-v3 --date D`):TRADER_v2 五模式候选 → 按上表过滤 → B 优先、同模式按 v2 模式分 → 预选池最多 10 只,冻结为 `plan.vN.json`(只增不改)。
2. **T 日 9:26**(`auction-v3 --date T`):只抓预选池内的腾讯行情(或 `--file` 给 9:25 记录,走 `data/auction.py` 白名单校验);竞价到涨停价或停牌的跳过,取第一只可买的。
3. **T 日开盘买入**,当天收盘看是否收涨。`history-v3` 按同样规则重放历史。

## 历史重放(每天 1 只)

| 区间 | 出手天数 | 当天收涨率(95% 区间) | 平均开→收(扣 0.15%) | 同期全市场收涨率 |
|---|---|---|---|---|
| 2024-10 ~ 2025-09 | 99 / 243 | 60.6%(50.5% ~ 69.7%) | +1.32% | 48.4% |
| 2025-10 ~ 2026-03 | 39 / 115 | 59.0%(43.6% ~ 74.4%) | +0.64% | 47.1% |
| 2026-04 ~ 2026-10 | 61 / 131 | 60.7%(47.5% ~ 72.1%) | +1.34% | 46.0% |

T 日竞价相对「预期竞价」的强弱(用 D 日数据回归 T 日跳空)试过,作为过滤没有稳定增益,没有放进规则。

## 必须知道的局限

- **开关是看过三段数据后定的**,没有干净的样本外;从 2026-10-19 起的前向记录才是检验。
- **成交价是理想化的**:日线开盘价 = 9:25 竞价价,但看到竞价结果后只能在 9:30 之后按连续竞价价格买,实际可能更差。
- 每段只有 39 ~ 99 笔,区间很宽;一半以上的交易日空仓。
- 退潮日 B 在 2025-10 ~ 2026-03 只有 27%(11 笔),是最不稳的一格。

## v4 改进(EXPECT_v4,当前默认)

来源:复盘 6-23、6-26 两个分歧日,v3 空仓但主线首板次日普遍收涨;7-01 复盘提出的修复日问题也一并检验。
每个想法都按「三段(训练 / 验证 / 留出)都不变差」检验,只采用一条:

| 想法 | 新增或换掉的出手 | 结论 |
|---|---|---|
| **分歧日做 B 首板接力** | 新增 84 天,当天收涨率 训练 62% / 验证 50% / 留出 65% | **采用**(三段都高于同期全市场 46% ~ 48%) |
| 分歧日做 E 中军 | 三段合计略降 | 不采用 |
| 分歧日做 C 龙头首次分歧(竞价不低开) | 验证期降到 50%、开→收为负 | 不采用 |
| 发酵日做 A 首板预判 | 验证期 48.7% | 不采用 |
| 发酵日做 C | 新增日子 训练 43% / 验证 46% | 不采用(只有留出期好) |
| 修复日首板竞价过热时改 A 优先 | 只换了 12 天的票,9 对 vs 8 对 | 噪声,不采用 |

| 区间 | v3 出手 / 收涨率 | v4 出手 / 收涨率(95% 区间) | v4 平均开→收(扣 0.15%) |
|---|---|---|---|
| 2024-10 ~ 2025-09 | 99 天 / 60.6% | 141 天 / 61.0%(53.2% ~ 68.8%) | +1.36% |
| 2025-10 ~ 2026-03 | 39 天 / 59.0% | 60 天 / 56.7%(43.3% ~ 70.0%) | +0.59% |
| 2026-04 ~ 2026-10 | 61 天 / 60.7% | 81 天 / 61.7%(50.6% ~ 71.6%) | +1.18% |

v4 让出手天数多了约四成(空仓日从约 60% 降到约 40%),收涨率基本持平;验证期分歧日只有 52%(21 笔),是新增部分里最弱的一段。
复盘过的日子里,v4 在 6-23 → 6-24 买津药药业 +2.3%,6-26 → 6-29 买凯盛科技 +1.6%,其余与 v3 相同(6-30 → 7-01 冰轮环境 −5.8% 仍未解决)。
⚠️ 分歧日这格同样是看过数据后加的,前向记录才是检验。
