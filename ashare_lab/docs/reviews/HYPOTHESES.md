# 复盘假设登记

逐日复盘发现的不足先登记为假设,**不在复盘日上直接改规则**(只看几个挑出来的日子去改,必然过拟合)。
攒够几个交易日后,把每条假设写成可执行规则,在验证期(2025-10-09 ~ 2026-03-31)整体检验,
通过的再进前向纸面交易;复盘过的日子只作为线索,不作为证据。
