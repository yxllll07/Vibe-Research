# 复盘假设登记

逐日复盘发现的不足先登记为假设,**不在复盘日上直接改规则**(只看几个挑出来的日子去改,必然过拟合)。
攒够几个交易日后,把每条假设写成可执行规则,在验证期(2025-10-09 ~ 2026-03-31)整体检验,
通过的再进前向纸面交易;复盘过的日子只作为线索,不作为证据。

已复盘:2026-06-23(→06-24)、2026-07-03(→07-06;用户指定 07-05 为周日,取前一交易日)。

## 下一步建议

- 再复盘几种不同状态的日子(状态 0 退潮、状态 2 温和普涨),避免只看情绪高潮日。
- 之后统一检验优先级:H6(分散)> H3(E 方向)> H7(账户风控)> H4(止损)。H1 / H2 已出现反例,降级。
