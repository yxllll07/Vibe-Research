# 竞价修复系统(RELAY_v1,当前主系统)

> 研究 / 纸面用途,不是投资建议。依据与检验见 `docs/REALIZABLE.md` 第 7 ~ 8 节。

## 它在做什么

每个交易日 9:25 后,用全市场主板可交易股票的**竞价跳空(相对 T 日参考价)+ D 日全部特征**,
预测「T 日开盘买、T+1 收盘卖还能赚钱」的概率,取前 5 名等权买入。

- 只用 D 日数据找不到「第二天还有人接」的票(5 年 AUC ≈ 0.51);竞价把隔夜信息和资金意愿暴露出来,才是信号来源。
- 选出来的多是冷门、偏弱、竞价被小幅错杀(中位数低开约 0.9%)的票,赚的是第二天的修复,不是热门接力。
- 5 年逐季前推(只用过去训练):前 5 名等权每笔 +0.45%,2022 ~ 2026 每年为正;按开盘价成交,未计 9:30 后的滑点。

## 每天怎么跑(北京时间,`scripts/` 里的定时脚本已接好)

| 时间 | 脚本 | 命令 | 产出(`.local/ashare_lab/system/relay/<信号日>/`) |
|---|---|---|---|
| D 日 20:30 | `daily.sh` | `relay-settle`、`relay-train --date D` | 台账 `ledger.md`;模型 `model.txt`、D 日特征快照 `snapshot.parquet`、`meta.json`(只增不改) |
| T 日 9:26 | `auction.sh` | `relay-pick --date T` | `pick.md`:全市场竞价约 3.5 秒拉完,竞价到涨停价 / 停牌跳过,前 5 名 |
| T 日 9:31 | `fill.sh` | `relay-fill --date T` | `fill.json`:前 5 名 9:30 后的现价(检验真实买入价) |
| T+1 收盘后 | `daily.sh` | `relay-settle` | 台账同时给出按开盘价和按 9:31 价的净收益 |

```
30 20 * * 1-5  cd /路径/Vibe-Research && ashare_lab/scripts/daily.sh   >> .local/ashare_lab/daily.log   2>&1
26 9  * * 1-5  cd /路径/Vibe-Research && ashare_lab/scripts/auction.sh >> .local/ashare_lab/auction.log 2>&1
31 9  * * 1-5  cd /路径/Vibe-Research && ashare_lab/scripts/fill.sh    >> .local/ashare_lab/fill.log    2>&1
```

## 规则

- **模型**:LightGBM 分类;目标 = T 开盘买、T+1 收盘卖(收盘跌停或停牌顺延到能卖的开盘)扣费后净收益 > 0;
  特征 = 个股 / 行业 / 市场 / 情绪周期 / 主线 / 龙头的 D 日特征 + 竞价跳空;每晚用卖出日 ≤ D 的全部样本重训(2021-08 起约 379 万行)。
- **买入**:前 5 名 9:30 后等权买入,单只不超过账户 4%(每天总敞口 20%,持仓最多跨两天 → 最多 40%)。
- **卖出**:T+1 收盘卖;收盘跌停或停牌卖不出,顺延到之后第一个能卖的开盘。
- **成本**:2023-08-28 起 0.15%,之前 0.2%(印花税减半)。

## 风险与未验证的部分

- **买入价**:回测按开盘价(= 9:25 竞价价)成交;买入价每比开盘价差 0.1%,每笔少 0.1%,差到约 0.4% 优势就没了。由 9:31 记录检验。
- **流动性**:这些票成交额中位数约 0.2 亿,大资金进不去。
- **2026 年最弱**(+0.20% / 笔);前向记录从 2026-10-19 开始。
- 情绪开关系统(`plan-v3`,`docs/SYSTEM_v3.md`、`docs/WALKFORWARD.md`)保留作对照,5 年可兑现约 0。
